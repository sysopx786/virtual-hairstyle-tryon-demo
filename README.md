# Virtual Hairstyle Try-On Demo

Standalone prototype for a virtual hairstyle try-on experience.

## Features
- Sample AI-generated before/after portraits (skin fade, textured crop, buzz cut, high fade)
- Upload your own photo or use the camera
- Pick a style from the gallery
- Side-by-side comparison

## How to run
1. Clone or download this repo
2. The `images/` folder contains the style photos
3. Open `index.html` in a browser

## Live site
https://sysopx786.github.io/virtual-hairstyle-tryon-demo/

## Notes
This is a UI prototype. Realistic hairstyle blending on arbitrary user photos requires a generative AI image editing backend.

Created for barbershop client visualization.
